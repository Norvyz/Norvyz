## Sobre mí

Soy estudiante de programación y actualmente estoy enfocado en **aprender, experimentar y desarrollar proyectos que me permitan comprender mejor el código y la lógica detrás de cada solución.**

Me gusta aprender haciendo. Cada proyecto que desarrollo representa una oportunidad para enfrentar problemas reales, investigar cómo solucionarlos y entender qué hay detrás de cada funcionalidad.

No busco simplemente hacer que algo funcione; quiero entender **cómo funciona, por qué funciona y cómo puedo mejorarlo.** 🧠
